# Offerlane architecture (P0 audit, 2026-11-09)

## Two codebases
- **This repo (`Offerlane-private`)**: the shipping product. Native Swift 6 macOS 14+ app. Builds the DMG.
- **`../Job Agent Kit`**: the earlier Python prototype (`jobagent`, stdlib HTTP server + web UI on :8765).
  Not called or embedded by the app. The Swift app is a port that replaces it (same prompts, same helper names).
  `Import/LegacyImporter.swift` imports data the Python prototype stored.

## Stack and entry points
- Project generated by XcodeGen from `project.yml`. App entry: `App/Sources/OfferlaneApp.swift` (`@main`).
- Engine: Swift package `Packages/OfferlaneCore` (GRDB store, LLM, Discovery, Tailor, Apply, Email, Setup).
- UI: SwiftUI (`App/Sources/**`), design tokens in `App/Sources/DesignSystem/`. SwiftTerm for the embedded terminal.
- Apply engine runs in the app process with WebKit (`App/Sources/Apply/`).

## Launch and packaging
- Dev build: `scripts/build.sh [Debug|Release]`.
- Release: `scripts/package.sh` → `dist/Offerlane-<ver>.dmg` (hdiutil) + `.pkg` (pkgbuild); signs, notarises and
  staples when `NOTARY_PROFILE` is set; then `scripts/privacy_gate.sh` and `SHA256SUMS.txt`.

## AI provider requests (OfferlaneCore/LLM/)
- `OllamaClient.swift`: OpenAI-compatible `POST {base}/chat/completions`, default base `http://localhost:11434/v1`.
- `AnthropicClient.swift`: `POST https://api.anthropic.com/v1/messages`.
- `ClaudeCLIClient.swift`: runs the Claude Code CLI via `ProcessRunner`.
- `AIFactory.swift` picks the client and the Ollama base URL. `OFFERLANE_FAKE_AI=1` swaps in the fake AI for tests.

## How discovery chooses companies
- Onboarding auto-runs `OnboardingModel.draftSearch()` (`App/Sources/Onboarding/OnboardingModel+Steps.swift`)
  → `SearchSetup.draft` (`Search/SearchSetup.swift`). The prompt asks for "Companies: 40-60 employers that hire this
  profile…" (smart model, 3500 max tokens); the results are de-duplicated by name, then `Careers.attachWorkday` runs.
  The user can add companies or ask again ("Suggest Again"). An empty list blocks the step.
- `Discovery.run` (`Discovery/Discovery.swift`): `let companies = search.companies`. It visits only those career
  boards (ATS adapters, 8 in parallel) with `targetTitles.prefix(3)` as queries.
- **That list is the only job source.** The 40-60 is a prompt instruction, not a code cap, but there is no
  JobSpy/aggregator source like the prototype had. So results are limited to the drafted (plus user-added) companies.
- Other limits: Workday `limit: 20` per query (`Adapters.swift`), AI scoring pool `prefix(poolSize)` (default 25,
  `Ranking.swift`, `Models/Profile.swift`), skills `prefix(40)` (`Ranking.swift`).

## Where data lives
- `~/Library/Application Support/Offerlane` (override with `OFFERLANE_HOME`; see `OfferlaneCore.swift`): GRDB database,
  resumes, caches.
- Secrets go in the macOS Keychain (`Security/Keychain.swift`).

## Tests (one command)
- `scripts/test.sh` (default `all`): contrast check, secret scan, `swift test` (OfferlaneCore), Xcode UI tests, and
  the in-app apply self-test against bundled mock sites. `scripts/test.sh real` runs the opt-in real-site smoke test.
- Baseline 2026-11-09: core 122 tests (6 skipped), 0 failures; UI tests pass; apply 14/14.
- The Python `tests/e2e.py` / `ui_test.py` belong to the prototype. Its dependencies aren't installed here, and
  e2e.py hits real job boards. They aren't part of this product's gate.
